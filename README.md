#  .NET React Portfolio

A full-stack developer portfolio built with **ASP.NET Core .NET 8 and React**, showcasing software development projects, technical skills, experience, and contact information.

##  Features

*  Developer profile and experience
*  Projects showcase
*  Technical skills
*  Contact form
*  Authentication and authorization
*  RESTful API integration
*  Responsive UI

##  Architecture

```text
React Frontend
      ↓
Ocelot API Gateway
      ↓
ASP.NET Core Microservices
      ↓
SQL Server
```

##  Tech Stack

**Backend**

* C#
* .NET 8
* ASP.NET Core Web API
* Entity Framework Core
* JWT Authentication

**Frontend**

##  Getting Started

Clone the repository:

```bash
git clone https://github.com/Gurpreet1523/DotNet-React-Microservices-Project.git
cd DotNet-React-Microservices-Project
```

Restore and build the .NET projects:

```bash
dotnet restore
dotnet build
```

Run the frontend:

```bash
npm install
npm start
```

Run the backend services using the appropriate .NET projects.
